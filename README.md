# E-SPORTS BD Web App

এটি একটি E-Sports ভিত্তিক ওয়েব অ্যাপ্লিকেশন, যা Progressive Web App (PWA) হিসেবে কাজ করে। এই অ্যাপ্লিকেশনে ইউজার এবং অ্যাডমিন两部分 (parts) রয়েছে।

## ফিচারসমূহ (Features)
*   **ইউজার প্যানেল:** ইউজাররা ওয়েবসাইটে এসে টুর্নামেন্ট বা ইভেন্ট দেখতে পারবে। (`user.html`)
*   **অ্যাডমিন প্যানেল:** অ্যাডমিনরা ইভেন্ট বা ইউজার ম্যানেজ করতে পারবে। (`admin.html`)
*   **PWA সাপোর্ট:** মোবাইলে এটি একটি অ্যাপের মতো ইনস্টল করা যাবে এবং অফলাইনেও কিছুটা কাজ করবে।
*   **ফায়ারবেস ইন্টিগ্রেশন:** ডাটাবেস এবং অথেনটিকেশনের জন্য ফায়ারবেস ব্যবহার করা হয়েছে।

## টেকনোলজি (Tech Stack)
*   HTML5, CSS3
*   JavaScript
*   Firebase (ব্যাকএন্ড সেবার জন্য)
*   GitHub Actions (অটোমেটিক ডিপ্লয়মেন্টের জন্য)

## ফাইল স্ট্রাকচার
*   `user.html` - ইউজারদের জন্য মেইন পেজ।
*   `admin.html` - অ্যাডমিন প্যানেল।
*   `firebase-config.js` - ফায়ারবেস কনফিগারেশন।
*   `.github/workflows/deploy.yml` - অটো ডিপ্লয়মেন্ট ওয়ার্কফ্লো।
*   `manifest-user.json` এবং `manifest-admin.json` - PWA ম্যানিফেস্ট ফাইল।

## সেটআপ ও রান করার নিয়ম
১. রিপোজিটরিটি ক্লোন করুন।
২. `firebase-config.js` ফাইলে আপনার নিজের ফায়ারবেস প্রজেক্টের API কী ও ডাটাবেস লিংক বসান।
৩. যেকোনো ব্রাউজারে `user.html` ফাইলটি ওপেন করে অ্যাপটি রান করতে পারবেন।
